# Audit du 8 octobre 2026 — QTZ et décisions de mise à niveau

## Périmètre

QTZ est la préférence personnelle prioritaire de l'utilisateur : **7500 points** sur les dix profils, contre TyHD **4900** et SpK79 **5400**. Langue, exclusions, tailles et incrément **1400** restent inchangés. À qualité égale, les scores se cumulent ; une équipe ne contourne pas une exclusion. Le cas fourni *La Momie* devient **21100 contre 18720**, soit **2380**, suffisant pour remplacer TyHD par QTZ selon le moteur de mise à niveau testé.

Versions observées : Profilarr **2.2.0**, parser **1.0.1**, Radarr **6.4.4.10685**, Sonarr **4.0.20.3014**. L'export API initial des dix profils correspondait au SQL 2.0.6, notamment les ordres et cutoffs. Cela ne prouve pas à lui seul la synchronisation de 2.0.7.

## Contrôles reproductibles

- `PARSER_URL=http://localhost:5000 python3 scripts/validate.py` : compilation SQL, 179 mutations de garde-fous, 592 cas CF, 44 compléments CF/tailles, 149 assertions de profils, 751 contrôles d'équipes interdites, 497 contrôles C411, tailles/durées, HEVC et documentation.
- `python3 scripts/verify_arr_snapshot.py export.json` : compare un export **GET uniquement**, sans clés API, au SQL courant. Les champs nécessaires sont décrits dans le script. Ce contrôle signale un déploiement resté aux anciens scores.
- `PARSER_URL=http://localhost:5000 python3 scripts/prepare_upgrade_cases.py export.json` : prépare 88 paires couvrant les dix profils. Sortie JSON sur stdout ; ne modifie pas les applications.
- [Moteur natif isolé](../../tests/native-upgrades/README.md) : appelle `UpgradableSpecification` des DLL copiées depuis les applications installées, sans démarrer Arr. **42 paires Radarr et 46 Sonarr** ; un export au classement 4K inversé doit faire échouer le test.

La suppression d'une source, l'inversion des qualités, un mauvais score, cutoff ou plafond de taille sont aussi des contrôles négatifs de l'export. Les copies de DLL et exports restent hors Git.

## Parser et limites

Le traitement `/match/batch` compile les regex et renvoie `false` lors d'un timeout de 100 ms, sans distinguer un échec technique d'une absence de correspondance. Sur le parser limité en CPU, les anciens essais produisaient des échecs variables. L'audit utilise désormais `/match` séquentiel, sans modifier les regex, avec vérification de l'exhaustivité et du type booléen des résultats. Ce point ne modifie pas le moteur de sélection Radarr/Sonarr.

Les paires utilisent les métadonnées du parser et les scores calculés par les conditions SQL. Elles valident la spécification native de mise à niveau, **pas** toute la chaîne de décision, l'évaluation complète des CF par Arr, la disponibilité des indexeurs, les tailles d'un candidat réel, le téléchargement ou l'import. Aucun film n'est supprimé ni téléchargé pour le test.

Les profils Séries et Anime coexistent sur une instance Sonarr ; les réglages de gestion des médias y sont globaux. L'instance observée applique le preset `FR-Media-Sonarr`, pas simultanément le preset Anime.
